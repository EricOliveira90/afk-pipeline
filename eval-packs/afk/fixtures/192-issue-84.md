# GH #84 — Gate policy reader (excerpt, as of 2026-09-07)

## Parent

#72 (PRD 4: Acceptance and scope gates). Settled decisions:
`.kiro/specs/afk-v2-acceptance-scope-gates/prd.md` D1 and D6's glob rule.
This slice runs first and creates the reader every later slice consumes.

## What to build

`afk.config.json` at the repo root gains one optional top-level `gatePolicy`
object, and a new module `src/gate-policy.ts` reads and validates it.

- This slice owns the module, the required `version` (literal `1`),
  `protectedPaths` and `riskClasses`. #85 later adds `acceptance`, #86 adds
  `cost`; each widens the known-key set as it lands.
- `protectedPaths` is an object of two optional string arrays,
  `gatePolicyPaths` and `testGlobs`. Absent, each defaults to the documented
  baseline: `["afk.config.json", "suite-budgets.json"]` and `["**/*.test.ts"]`.
- `riskClasses` is a flat array of the literal strings `gate-policy`,
  `deleted-test`, `skipped-test`. The risk-class-to-path association is code in
  this module, not config.
- A malformed object **or an unknown member** refuses the launch, naming the
  offending key. Silently ignoring an unknown key is the defect D5 exists to
  remove.
- When `gatePolicy` is absent entirely, every consumer falls back to today's
  derived baseline catalog in `src/base-gates.ts` and behavior is unchanged.

**The glob matcher** for `testGlobs` is also yours, exported from this module:
literal segments, `*` (within one segment) and `**` (zero or more segments), over
paths normalized to forward slashes, **case-sensitive on every platform**. Any
other metacharacter in a `testGlob` refuses the launch and names the character.
AFK has **no runtime dependencies**; do not add one.

Note `gatePolicy.version` is its own schema version, independent of
`afk.config.json`'s existing top-level `version`. The file's `resourceKeys` and
`architectureDoc` are untouched.

## Acceptance criteria

- [ ] A malformed `gatePolicy` object refuses the launch and names the offending key.
- [ ] An unknown member of `gatePolicy` refuses the launch and names that member.
- [ ] A `gatePolicy` whose `version` is absent or is not `1` refuses the launch.
- [ ] With no `gatePolicy` present, the derived baseline catalog in `src/base-gates.ts` is used and current behavior is unchanged.
- [ ] A `gatePolicy` omitting `protectedPaths` or `riskClasses` parses and returns the documented baseline defaults.
- [ ] An unrecognised string in `riskClasses` refuses the launch at parse time, naming it.
- [ ] `loadGatePolicy` returns the validated policy for a repository whose `afk.config.json` carries a well-formed `gatePolicy`, and `null` when the file is absent or carries no `gatePolicy`.
- [ ] The glob matcher matches `**/*.test.ts` against a nested test path and does not match a non-test path.
- [ ] The glob matcher is case-sensitive: a path differing only in case does not match.
- [ ] A `testGlob` containing any metacharacter other than `*` refuses the launch and names the character.

preference: a revision round's evaluator prompt inlines *both* the original and
the revised pair, so a 30 KB pair makes round 2 structurally unreachable against
the 65,536-byte inline budget, and the slice dies at `CONFIGURATION` rather than
on its merits.

contract is honest: state each behavior once, cite `prd.md` and this issue by
reference rather than restating them, do not mirror the anchors file into
`contract.md`, and use the repository's tracked casing for every declared path.
