## Data and integration

- FACT: `snapshotPath` is a repo-relative directory string (e.g. `slices/07-fixture/recovery-snapshots/attempt` in the test fixture) holding the byte-verified accepted-pair snapshot that `restoreAcceptedPairFromSnapshot` reads from and restores to the accepted pair location.
- FACT: `attemptId` is opaque and, per `preserve-work-recovery.ts:277`(-area) comments, is never reused by a retry — a new attempt after reconciliation gets a new attempt ID and a new snapshot (matches the acceptance criterion "may admit a new attempt with a new attempt ID and a new snapshot").
- FACT: Restoration touches only the accepted-pair snapshot files; ADR 0039 is cited directly in `preserve-work-recovery.ts:1361-1363` for the invariant that rollback "touches no ref, no commit, no preserved worktree" — this is the basis for the acceptance criterion that reconciliation runs no git merge/reset/rebase and leaves the preserved worktree, slice branch and commits unchanged.
- FACT: All run-state mutation (including any reconciliation append) must go through `transactRunState`'s single cross-process lock per run-state file (ADR 0056, `docs/adr/0056-one-cross-process-lock-per-run-state-file.md`).
- FACT: ADR 0055 (`docs/adr/0055-...durable-replaceable-park.md`) governs the "one contract-mutation transaction, one lock predicate" discipline already used by `reconcileDiscardedDecisionLog`'s park-state handling (cited in `orchestrator.ts:2682-2703,2763`) — relevant as the general transactional-locking precedent, though that call site itself is not the pre-resume one the issue describes.
- FACT: ADR 0060, 0061, 0062 are not primarily about recovery-lineage ordering or restore verification: 0060 governs parser-contract regression surfaces, 0061 governs informing a refused negotiation artifact once before it becomes terminal (adjacent "durable lineage" language but about negotiation artifacts/prompts, not recovery events), 0062 governs contract-revision-round record shape. None is cited as directly governing in the module code inspected.
